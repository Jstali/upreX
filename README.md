## ⚡ Overview

**uperX** is an award-winning digital engineering studio platform built with **React**, **TypeScript**, **Three.js (WebGL)**, and **Vite**. Inspired by modern creative engineering, the website features:

- **6 Core Offerings**:
  1. **Autonomous AI Agents & Multi-Agent Swarms**
  2. **Custom Full-Stack Software Development**
  3. **High-End 3D WebGL & Creative Spatial Frontends**
  4. **Service-Based Applications & SaaS Platforms**
  5. **Algorithmic Growth Marketing & Conversion Optimization**
  6. **Enterprise IT & Cloud Operations (AWS/GCP/Kubernetes)**
- **Interactive AI Agent Terminal**: Real-time multi-agent execution simulation.
- **3D Porsche 911 Studio**: Real-time WebGL PBR car configurator with dynamic wrap swatches.
- **Interactive Splat Mode**: 3D cursor-following paintball gun with recoil and audio effects.
- **Liquid Glass Page Transitions**: Frictionless, Apple/Linear-inspired cross-dissolve with zero-layout-blocking and top cyber laser progress beam.
- **Lenis Smooth Inertial Scrolling**: 60fps/120fps momentum damping with off-screen GPU optimization.
- **Desktop OS v3.0**: Interactive desktop environment with neural command folders, custom sticky notes, and wallpaper customizer.

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **3D & Creative Motion**: Three.js (WebGL), GSAP, Lenis Smooth Scroll
- **Tooling & Build**: Vite, PostCSS, Autoprefixer
- **Hosting & Edge**: Vercel Global Edge Network with client-side SPA rewrites

## 🚀 Quick Start

### 1. Clone the repository:
```bash
git clone https://github.com/Jstali/upreX.git
cd upreX
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production:
```bash
npm run build
```
